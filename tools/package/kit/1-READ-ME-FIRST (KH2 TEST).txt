=========================================================================

This is a TEST. It lives in its own folder (PS2-ONLINE-KH2-TEST). Your normal PS2-ONLINE folder is not changed
and is not used. BOTH players must use this test folder, not the normal one.

What it is: Kingdom Hearts II Final Mix with a second hero. Player 1 plays the game's hero (Roxas at the start,
Sora later). Player 2 plays a second copy of the same hero with their own controller.

HP gauge, full size. The small round gauge is the other player. Both heroes are still in the same room.

------------------------------------------------------------------
STEP 1: MAKE THE TWO-PLAYER DISC FILE (each player, once, about 3 minutes)
------------------------------------------------------------------
You need your OWN original disc file "Kingdom Hearts II - Final Mix (Japan)" (.iso, 4,330,192,896 bytes).
1. Open the folder MAKE-KH2-DISC and double-click MAKE-KH2-DISC.bat.
2. A window asks for your original disc file. Choose it. (Or drag the file onto MAKE-KH2-DISC.bat.)
3. Wait for the five steps. Your original file is only read. A NEW file is written into this folder's
   "MY-GAMES (never share)":  Kingdom Hearts II - Final Mix (2 Players TEST v5).iso
4. At the end it must say OK and show this check number:
       c0d652c46c603c093653d58f2506503a5089ce9c
   Both players must get exactly this number. If it says NOT DONE, read the red text.
Keep ONLY this one Kingdom Hearts file in this folder's MY-GAMES. Do not put the original disc file there.

------------------------------------------------------------------
STEP 2: THE SAME MEMORY CARD ON BOTH PCs
------------------------------------------------------------------
- At the first start neither player has a memory card in this test folder. The emulator makes a new empty one,
  the same on both PCs. Nothing to do.
- The first time you save, the game says "MEMORY CARD in slot 1 is not formatted. Format it?". The cursor is on
  No: press Left, then Circle (Yes).
- If you always play this test folder together, both cards stay the same.
- If the game window says "Different memory card": close the game on BOTH PCs. Then either both delete the file
  emulator\memcards\Mcd001.ps2 (the test saves are lost), or the host sends that one file to the friend
  (it holds only the test saves) and the friend puts it into emulator\memcards.

------------------------------------------------------------------
STEP 3: START
------------------------------------------------------------------
1. Double-click START-KH2-TEST.bat. The window is called "PS2 Online - KH2 two-player TEST".
   - Close your normal PS2-ONLINE first: the two cannot run at the same time (they use the same network ports).
   - Windows may ask about the firewall again, because this is a new folder (for "pcsx2-qtx64" and
     "ps2net-link"). Tick BOTH boxes, "Private networks" AND "Public networks", then click Allow.
2. Game: the "2 Players TEST v5" file (new in build 12). Controllers: "2 players, no
   multitap". Screen: "Normal 4:3" (as the game was made). "Widescreen 16:9" also worked with own screens in one
   test; it is the host's choice.
   Picture quality: "4x High" on BOTH PCs (see the top of this file).
3. HOST: press "Host a game" and send the join code. FRIEND: paste the code, press "Join". Same as in the normal
   package (reply codes, Join by IP and Radmin work the same way; see "PS2-ONLINE general help.txt").
4. The first time, the launcher checks the game file (up to a minute). Then the box "What is happening" shows
       Game file check: XXXX-XXXX-XXXX-XXXX
   It must be the same on both PCs. If the friend's file is different:
   - joining with a code says so in the launcher;
   - joining by IP is refused in the game window with "Different patch files in the emulator's patches folder".
     In this test folder that message also means "the two game files are not the same".
5. Title screen: New Game with Circle. Every question: Circle. The opening movie and story scenes can be skipped
   by either player: START, then Down, then Circle ("Skip Scene").

------------------------------------------------------------------
BUTTONS (Japanese disc layout, NOT changed)
------------------------------------------------------------------
  Circle   = confirm in menus; attack / use the selected command
  Cross    = cancel in menus; jump
  Triangle = Reaction Command (when the green command shows)
  Square   = guard / dodge roll (after the skill is learned)
  R1 = lock on, L1 (hold) = shortcuts, left stick = move, right stick = camera (player 1 only for now)
  START    = main menu; in a scene: skip (either player)
Xbox pad: B = Circle, A = Cross, Y = Triangle, X = Square. Keyboard: L = Circle, K = Cross, I = Triangle,
J = Square, Enter = START, arrows or WASD = move, Q / E = L1 / R1.
The English text names the right buttons for this layout ("Jump with Cross"). A few tutorial PICTURES may still
show the US buttons.

WHAT WORKS IN THIS BUILD
------------------------------------------------------------------
- NEW: own screens. Each PC shows its own hero with its own camera (right stick), its own command menu and
  cursor, its own big HP / MP gauge and its own lock-on ring. The small round gauge shows the other player.
  When the game takes the camera (story scenes, the pause menu, the save menu, Game Over) both PCs show the
  same full picture, and own screens come back afterwards.
- A second hero stands beside player 1's hero in every room and in every form tried so far (Roxas, Sora, the lion,
  the costumes).
- Each hero is moved by its own controller: run, jump, attack and combos, guard, dodge, magic through the L1
  shortcuts, own lock-on target. Each hero walks by its own camera.
  Each hero's attacks go for his own target (in build 3 player 2's swings used player 1's target).
- Each hero has its own HP, MP and Drive gauge. Each player's hits fill only his own Drive gauge.
  Level and the abilities learned are common. Each player has his own armour and accessories (since build
  15), switches his own abilities (since build 19), has his own Keyblade, item places, fight items and
  shortcuts (since build 20) and his own wallet and bag (since build 21).
- Enemies and bosses attack BOTH heroes. They go for the nearer hero; when both are near they take turns.
- A hero whose HP reaches 0 goes DOWN and stays in the room, like Goofy. He gets up by himself after 45 seconds
  in a fight (a few seconds outside a fight) with a quarter of his HP. The other player can bring him back sooner
  with a Potion or with Cure (stand near him). It is Game Over only when BOTH heroes are down at the same time;
  Continue then brings both back.
- Room exits. Both heroes must be at the exit: one in the doorway, the other within a few steps. While one hero
  waits there the screen says "Waiting for the other player." No exit while a hero is down.
- Bosses have 75 % more HP than in the original game, because two heroes hit them (Pete in the Underworld cave:
  40 % more, because of his time limit). Normal enemies are as in the original.
- Tutorial boxes and talk text can be closed by either player (Circle).
- Either player can open the main menu with START, move in it and close it. The save menu works with either
  controller too. While a menu is open the game waits for both players, and both screens show the menu.
- Both heroes pick up what enemies drop. A ball's HP, MP or Drive goes to the hero who took it and to nobody
  else (tested for HP, MP and Drive taken by player 2: the Drive test made the HP balls give Drive); munny goes into
  BOTH wallets (since build 21; before: the one wallet).
- Saving works (one shared save). Since build 22 the save holds BOTH heroes' Drive gauges; after Load Game each
  hero has his own again (before: both started with player 1's).
- NEW: Drive Forms for both players. Each player picks Drive in his own menu. Only that player's hero changes;
  he gets the form's gauge and the commands "Revert" and the form's own on his screen. He keeps the form through
  a door. SINCE BUILD 13 BOTH HEROES CAN BE IN A FORM AT THE SAME TIME (tested: Valor with Wisdom, Limit Form
  with Limit Form, Limit Form with Final). A form's row is dim for you only when the helper it needs is away
