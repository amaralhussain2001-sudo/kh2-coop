------------------------------------------------------------------
ONCE: PUT THE SAME FOLDER ON THE SECOND PC
------------------------------------------------------------------
1. Copy the WHOLE folder PS2-ONLINE-KH2-TEST to the second PC (USB drive or network share, about 4.5 GB).
   Put it anywhere, for example on the Desktop. Change nothing inside.
2. That is all. Both PCs now have the same program, the same disc file and the same memory card.
   (Copy the folder again whenever I give you a new build. Your saves are in emulator\memcards\Mcd001.ps2;
   keep that file if you want to keep them.)
   BUILD 12 HAS A NEW DISC FILE ("TEST v5"). Delete the old folder on the second PC and copy this one.
   BUILDS 13 TO 24 KEEP THAT DISC FILE; only small files changed. Copy the whole folder to the second PC again all the
   same (it is the sure way: both PCs must have exactly the same patch files).

------------------------------------------------------------------
EVERY TIME: START
------------------------------------------------------------------
1. BOTH PCs: close the normal PS2-ONLINE if it is open. Double-click START-KH2-TEST.bat in the folder.
   The first time Windows asks about the firewall (for "pcsx2-qtx64" and "ps2net-link"):
   tick BOTH boxes (Private and Public), then Allow.
2. BOTH PCs: Game = the "2 Players TEST v5" file. Controllers = "2 players, no multitap".
   Screen = "Normal 4:3". Picture quality = "4x High" on BOTH PCs.
   (If the second PC is too slow at 4x: choose the same lower value on both, 3x or 2x. Never "Auto".)
3. FIRST PC (player 1): press "Host a game".
4. SECOND PC (player 2): type the first PC's address into box 3 and press "Join by IP".
       The first PC's address when this text was written: {IP}
   It can change. To see it: on the first PC open "cmd", type ipconfig, read "IPv4 Address" (the one that starts
   with 192.168 or 10; not the 26.x.x.x one, that is Radmin).
5. Wait about 10 seconds. The game starts on both PCs at the same time.
   The first time, each PC checks the game file (up to a minute). The line "Game file check" in the launcher
   must show the same number on both PCs.
6. Title screen: New Game with Circle. Scenes can be skipped by either player: START, then Down, then Circle.

------------------------------------------------------------------
WHO IS WHO
------------------------------------------------------------------
- The FIRST PC shows player 1 (the game's hero). The SECOND PC shows player 2 (the second hero).
  Each PC shows its own hero, camera, command menu and gauge. The small round gauge is the other player.
- Each PC uses its own controller. If the pad on the second PC does nothing: button "Controller settings"
  in the launcher > Settings > Controllers > Controller Port 1.
- Buttons (Japanese layout): Circle = confirm and attack, Cross = cancel and jump, Triangle = green command,
  Square = guard. Xbox pad: B = Circle, A = Cross, Y = Triangle, X = Square.

------------------------------------------------------------------
SAVES
------------------------------------------------------------------
Both PCs must have the same memory card file. If you always play the two together, they stay the same.
If the game window says "Different memory card": close the game on both PCs, then copy the file
    emulator\memcards\Mcd001.ps2
from the first PC to the same place on the second PC.

------------------------------------------------------------------
IF SOMETHING GOES WRONG
------------------------------------------------------------------
Write down what you did and which player it was. Then copy the second PC's folders "logs" and
"emulator\logs" to the first PC (any place) and tell Claude: "read the logs", with the place.
"OUT OF SYNC" on the screen almost always means two different picture qualities or two different folders.
SAVE OFTEN. "Continue" after a Game Over inside a fight was tested in three fights (it goes back to the room
before the fight and plays its scene again; START skips it). If the game ever stops there, close it on both PCs,
start again and choose Load Game.

What is in the game and what is new: "1-READ-ME-FIRST (KH2 TEST).txt" in the folder.
