# Parity checklist: every world, mission, minigame, special sequence and boss, for two players

Written 2026-11-10 by lane P for the user's requirement `docs/REQUIREMENT-full-parity.md` (plan section 4B, Phase 3A).
This is the audit that comes BEFORE any special sequence is implemented. It does not design solutions and does not
promise that anything is possible. The same rows are in `docs/PARITY-CHECKLIST.csv`, with two empty columns to tick
later (`checked_with_two_players`, `date_checked`) and one more column, `data_facts`, holding what the game data
says about every mission file of the row.

**How to read the labels**

- **Judgment** (a first sorting, not a result): **BASE** = nothing in the data says more than the base is needed
  (the twin from a second PLAYER placeholder, own controller, own HP and MP, own commands, exits for two), to be
  confirmed; **OBJECT** = needs a second special object, vehicle or character state; **ADAPT** = the sequence
  itself was built for one and must be adapted; **UNKNOWN** = not known.
- **Ev** (evidence): **V** = the wording only restates game data; **V+M** = the data facts are VERIFIED, the
  description beyond them is FROM MEMORY, TO CONFIRM IN PLAY; **M** = FROM MEMORY, TO CONFIRM IN PLAY.
  Data means: the 303 mission files and their objective texts, the room scripts and spawn data of all 289 rooms,
  the object list, the party table, the command table and the English text (lane C's lists and
  `local/analysis/lane-p/`).
- **Phase** = the plan phase that should own the row.
- 'Base open items' used in many rows (from lanes D, E, G): enemies attack only the hero the engine holds as its
  player; either hero at 0 HP gives Game Over; no prompt, menu or gauge is drawn for player 2; START and all menus
  listen to controller 1; items, Drive, Limits and Summons through player 2 are untested.

## 2. Recommended order of the feasibility tests

Story order; inside a world the cheapest test first. Each is a short experiment in the style of the twin test:
build a jump disc, run it with the merged patch, look, write down. None of them is a promise.

1. **Base, before everything.** Merged build (lane M): own controller, own HP, own commands, exits, twin everywhere, all in one test run. GW-07 (magic drains own MP), GW-01 (P2 uses one enemy Reaction Command), GW-10 (only P2 falls).
2. **Twilight Town, Roxas.** TTR-09 Struggle: only pad 2 collects orbs, read both counters (also answers TTS-06). Then the job counters TTR-04 to TTR-08 the same way. Then TTR-03 / TTS-07 skateboard: both press Hop On at one board; find the board object and place a second. Then TTR-13 the bag and TTR-15 Twilight Thorn: both pads press Triangle in the same window.
3. **Hollow Bastion.** HB-05 Demyx and HB-07 the 1000 Heartless: does the kill counter count P2's kills? HB-08 Sephiroth: does his single-target attack ever pick the twin?
4. **Land of Dragons, Beast's Castle.** MU-09 Storm Rider and BB-07 Dark Thorn: the first 'carried by a Reaction Command' tests with a party present. BB-09 Xaldin: does P2 get an own Learn stock?
5. **Olympus.** HE-01 Cerberus (Auron only) and HE-06 Hydra (Pegasus ride). Then HEC-03 Titan Cup: let each hero be hit once and read the point pool; HEC-02 Cerberus Cup: Drive 'alone' for each hero (needs GW-04 first).
6. **Disney Castle, Timeless River, Port Royal.** DC-01: P2 calls Minnie. CA-08: watch one ship ambush with two heroes to learn what it is.
7. **Agrabah.** AL-06: repeat lane J's carpet test with the helper object copied too, to find what makes a carpet; only then AL-08. AL-07 needs a start played in from the story, because a jump disc shows a black screen (lane J).
8. **Halloween Town.** NM-07 Gift Wrapping: lane J's two-cannon disc with the merged patch: does the second cannon aim and fire on pad 2?
9. **Pride Lands.** LK-05 Groundshaker: both lions press the climb command.
10. **Space Paranoids.** TR-03 Light Cycle: lane J's two-cycle disc with the merged patch: does each cycle follow its own controller? TR-08: can both hold Delete?
11. **The World That Never Was.** EH-03 Luxord: watch the two time gauges when each hero is hit; let each be turned into a die. EH-01 Roxas: P2 answers the duel command. EH-09 the dragon: find what makes the bike. EH-11: let Xemnas catch each hero in turn.
12. **100 Acre Wood.** PO-01: lane J's two-flyer disc with the merged patch (own controller?). Then PO-02 and PO-03 with a second PO07_PLAYER / PO08_PLAYER placed. PO-05: just watch it with a twin.
13. **Atlantica.** LM-01: in one song press only on pad 2: does the game accept it at all?
14. **Gummi Ship.** GM-01: find where the Gummi mode reads the controller (the method lane A used for the player), then try giving a Teeny Ship to pad 2. This is a study of its own.
15. **Game-wide, in parallel.** GW-04 Drive Forms: each pad selects Valor in turn with Donald and Goofy present; then GW-05 one Limit per player, GW-06 one summon per player.
16. **Final Mix extras, last.** FM-06 Marluxia (whose count falls), FM-02 Vexen (whose data fills the gauge), FM-04 Zexion (who is trapped), FM-08 the Lingering Will; the mushrooms' counters with the job-counter result in hand.

## 7. What could not be determined from the data

- **What most sequences are like to play.** The mission files give an objective sentence, flags, counters and the objects in the room. How a sequence feels, which Reaction Commands it uses and what a boss does are FROM MEMORY in this document, and every such row is marked V+M or M.
- **Who offers which Reaction Command** (section 5): decided by enemy and object scripts, which were not read.
- **Which mission file is which Atlantica song**, and which mushroom file is which number: read from names and list order only.
- **Which friends a Drive Form or a summon uses up**: not in the command, limit, summon or form tables (lane C).
- **What makes the Magic Carpet and the flying bike**: copying the player object does not bring a second vehicle (lane J).
- **The skateboard object**: the tricks are commands in the table, but the board itself was not identified in the object list.
- **The Gummi Ship mode**: only its file names, route names and menu text were read.
- **Story order and story state.** The data lists every program that exists, not when the story uses it. Jump discs give a fresh level-1 save, so second visits and late-game states were not seen (lanes B and J).
- **Whether each mission's counter counts player 2's actions**: no test yet; this is why score rows carry a test.
- **HB13_MS902, SHIP_BATTLE, PO01 (The Hunny Pot)**: the data does not say enough to describe them.
- **Sequences without any mission file** that only a playthrough will show (scripted walks, forced events between fights, tutorials given by text boxes alone).
